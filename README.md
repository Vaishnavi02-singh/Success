# Success Message UI

A simple and clean **Success Message UI** created using HTML and CSS.

## 📌 About the project
This Project displays a success message after an action is completed successfully.
It includes a simple message box with a heading, discription, and **OK** button.

## ⚡ Features
👉Clean and simple UI
👉Success message box
👉Styled OK button
👉Proper alignment and spacing
👉Beginner-friendly HTML & CSS Project

## Preview
The project contains a centered success message card with a green border and an OK button.
